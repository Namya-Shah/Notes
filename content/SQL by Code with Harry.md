- DBMS
	- Database Management Systems

| Relational Database Management System                                                 | Non-Relational Database Management System                                         |
| ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Follows a fixed and predefined schema                                                 | Does not enforce a fixed or consistent schema                                     |
| Data is organised into structured tables with rows and columns                        | Provides flexible data storage and modeling                                       |
| Ensures data integrity through constraints and relationships                          |                                                                                   |
| Utilizes SQL (Structured Query Language) for defining and manipulating data.          | SQL is not mandatory for data manipulation and querying                           |
| Well-suited for applications requiring complex queries and transactional consistency. | Ideal for use cases where read operations are more frequent than write operations |
