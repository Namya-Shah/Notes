# Notes
- Text embeddings allow us to make text computable
## Difference between LLMs and Embeddings
| LLMs                         | Embeddings                       |
| ---------------------------- | -------------------------------- |
| ✅ Can perform tasks directly | ❌ Requires downstream analysis   |
| ✅ Bigger/More capable        | ❌ Typically smaller/less capable |
| ❌ Computationally expensive  | ✅ 100x Cheaper                   |
| ❌ Limited by context window  | ✅ Applicable to big datasets     |
| ❌ Unpredictable responses    | ✅ Deterministic Output           |
- **Requires Downstream Analysis**
	- As embeddings give numerical outputs which is not understandable by human so we need to do some analysis to get output
