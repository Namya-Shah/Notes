An **iteration** is one complete cycle of:
- Computing the predictions for all training samples,
- Calculating the cost function
- Computing the gradients
- Updating the parameters using the gradients
# Decide when to stop iterating
1. **Fixed Number of Iterations (Epochs)**:
	- You set a maximum number (e.g., 1500 iterations) and run the gradient descent loop that many times.
2. **Convergence Criterion**
	- You continue updating until the change in the cost function (or the parameters) between iterations is smaller than a specified threshold.# Notes
