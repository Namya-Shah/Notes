# Brief Introduction
Gated Recurrent Unit or GRU is like a memory cell that helps AI model remember important information while forgetting irrelevant details.
- New generation RNNs
- GRU's got rid of the cell state and used the hidden state to transfer information
- Little speedier to train than [[Long Short-Term Memory (LSTM)]] but not a clear winner
- **Update Gate:** decides what information to throw away and what new information to add
- **Reset Gate:** decides how much past information to forget
