# Gradient Descent
Gradient Descent is an optimization algorithm used to minimize a loss function in machine learning and deep learning models.
$$
\theta = \theta - \eta \cdot \nabla_\theta J(\theta)
$$
Where
$\theta$ : parameters (weights)
$\eta$ : learning rate
$J(\theta)$ : loss function
$\nabla_\theta J(\theta)$ : gradients of loss w.r.t parameters
