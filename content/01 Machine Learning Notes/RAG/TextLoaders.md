# Brief Introduction
- TextLoader is the simplest document loader, perfect for beginners and the "hello world" of RAG ingestion.
- It reads a raw .txt file and converts it into a clean LangChain Document with both content and metadata.
- This structured output ensures smooth processing when chunking, embedding, or storing in vector databases.
- Ideal for early prototyping, since .txt files are common, lightweight, and easy to iterate with.
- Avoids copy-paste chaos by instantly making files like cricket.txt ready for your entire RAG pipeline.
