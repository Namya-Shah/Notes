# Brief Introduction
- **CSVLoader is designed for structured datasets**, turning CSV files -- one of the most common real-world formats -- into LLM-friendly documents.
- Rather than merging the whole CSV, it converts each row into its own Document, making every record a clean, independent knowledge unit.
- This row-level structure helps LLMs understand context, columns, and relationships far better than raw CSV text.
- Enables powerful applications like recommendation systems, customer segmentation bots, resume filters, data auditors, and dataset exploration assistants.
- Makes it effortless to load CSV data and feed it into a RAG pipeline for searching, chunking, reasoning, or building intelligent agents.
