# Brief Introduction
- **DirectoryLoader is built for bulk document ingestion**, letting you load entire folders instead of individual files.
- It **automatically scans a directory**, matches files using patterns like `*.pdf`, and routes each file to the correct loader.
- This removes repetitive code -- whether a folder has 5 PDFs or 500, one command handles them all.
- It supports **lazy loading**, which loads files only when needed, making it ideal for large datasets and memory-heavy projects.
- Perfect for scalable RAG systems that ingest libraries, batches of reports, or large collections -- clean, efficient and production-friendly.
