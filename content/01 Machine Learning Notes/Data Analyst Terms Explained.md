1. Data Lake
    - Data Lake is a storage repository that can store vast amounts of raw data in its native format.
    - It handles structured, semi-structured and unstructured data and it offers massive scalability and is usually based on distributed and often open-source technology.
    - Amazon S3 is probably the most popular storage platform to build and store data lakes.
2. Data Warehouse
    - Data warehouse is a centralized repository designed for query and analysis. It integrates data from multiple sources and is optimized for data analytics and reporting.
    - A retail company can use a data warehouse to combine sales data inventory levels and customer information to optimize stock levels and improve customer satisfaction.
3. Data Mart
    - Data mart is a subset of data warehouse it focuses on a specific business functions or department for example, sales and finance.
    - It is designed for a specific community of knowledge workers
    - A sales data mart could provide the sales team with easy to access data on customer purchases helping them to analyze trends.
4. Data Wrangling
    - Data wrangling is the process of cleaning, transforming and organizing raw data in a structure and usable format.
    - It involves task like removing duplicates, handling missing values and converting data types.
    - For example, transforming raw sales data into a standardized format with consistent units allow business to compare performance and make informed decisions.
5. Data Integration
    - Data integration is the process of combining data from different sources or different formats and systems into a unified and consistent view.
    - It could involve a merging customer data from online sales and in-store transactions so that you can help retailers gain a holistic view.
6. Data Modeling
    - Data modeling is the process of creating a structure representation of real world data. It’s like designing a blue print that defines how data should be organized.
    - For example, in an e-commerce company data modeling helps define how customers, orders, products and reviews are related and stored in a database making it easier to retrieve and analyze information effectively.
7. Data Mining
    - Data mining is the process of discovering patterns, correlations, anomalies and statistically significant information from large datasets.
    - Companies can use data mining to analyze customer purchase history and identify products preferences
8. Data Visualization
    - Data visualization is the art of presenting complex data in visual forms like charts and graphs to basically make it easily understandable. It helps professional grasp trends, patterns and relationships in data.
    - For example, a sales chart can visually display revenue trends over time helping the business to identify growth opportunities or areas that need improvement.
    - The two most popular visualization tools are tableau, and powerbi
9. Data Schema
    - Database schema is an abstract design that represent the storage of your data in a database and so it describes both the organization of data and the relationships between tables in a given database.
    - Developers plan a database schema in advance so that they know what components are necessary and how they will connect to each other.
10. Structured, Unstructured, and Semi-Structured Data
    - Structured data is organized in rows and columns often in a database.
    - For example, a relational database like SQL with the clear tables and schemas.
    - Unstructured data is the data that doesn’t have a specific format organization.
    - For example, emails, videos and social media posts.
    - Semi-Structured data has some organizational properties but not as strict as structure data.
    - For example, JSON or XML files with TXT
11. Descriptive Statistics
    - Summarizing and presenting data to gain insights.
    - In industry it's used to understand trends, patterns and key characteristics of a data set using.
    - For example, methods like the mean, the median, and the mode and so retail companies might use.
    - Descriptive statistics to analyze sales data revealing the average number of sales or the highest selling products
12. Inferential Statistics
    - Inferential statistics which involves drawing conclusions and making predictions about a population based on a sample of data.
    - It helps us make informed decisions by analyzing a subset of data to infer insights about the entire population and so a car manufacturer might use in French statistics to estimate the average fuel efficiency of all vehicles produced based on a sample of cars that are tested.
13. Skewness
    - A measure of the asymmetry of the distribution of a variable around its mean.
    - If the curve is shifted to the left or to the right is said to be skewed.
    - Positive skewness indicates a distribution that is skewed towards the left while negative skewness indicates a distribution that is skewed to the right.
14. Correlation
    - Correlation measures the strength and direction of a linear relationship between two variables.
    - In industry, it helps uncover connections between different factors.
    - For example, a positive correlation between advertising, spending and sales indicates that highest spending often leads to increased sales and this influence the marketing strategies.
15. Causation
    - Causation refer to the cause and effect relationship between two variables where a changing in one variable directly influences a change in another.
    - For example, a e-commerce company can find that offering free shipping all the time increases sales
    - Correlation means that two variables change together while causation implies the changes in one variable directly influence the other.
16. Regression Analysis
    - It is a statistical method to model the relationship between a dependent variable and one or more independent variables often used for prediction and understanding variable relationships.
    - If a company observes that increased advertising which is the independent variable usually leads to higher sales which is dependent variable then they can use regression to quantify the relationship and predict future sales from plan advertising expenses.
17. Outliers
    - Outliers refers to a data point that deviates from the overall pattern of a data set.
    - Outliers can impact analysis and decisions. In finance, unusually high stock price on a certain day might be a outlier.
18. Normalization
    - It is a data pre-processing technique that scales features to a common range.
    - For example, between 0 and 1 in a customer database normalizing income and age helps a bank evaluate loan applications fairly preventing one feature from dominating the decision making process due to its large scale.
19. Data Governance
    - It involves creating and enforcing rules, processes and policies for managing data across the organization.
    - It ensures data quality, security and compliance. It basically helps companies to maintain accurate and reliable data.
    - For example, a health care organization use data governance to ensure that patient records are securely stored and accessible only to authorized personnel.
20. Extract Transform and Load
    - ETL are process used in the industry to gather data from various sources which is the extract then clean structure and enrich it which is transform before finally loading into a storage or database for analysis which is the load part.
    - Companies can use ETL to gather sales data from different stores standardize the format and load it into a centralized database.
21. Extract Load
    - Extract load and transform which is a newer method for achieving the integration of data from across an organization.
    - Here data is extracted from its origin loaded into the data store and then transformed and so the transform action will typically happen on a as needed basis versus the ETL.
22. Time Series Analysis
    - TSA involves studying data points that are collected at evenly spaced intervals over time and it’s used to forecast future trends.
    - For example, a utility company might analyze historical energy consumption patterns to predict demand ensuring that they allocate the resources in appropriate way.
23. AB Testing
    - AB testing is a method where two versions A and B of something are compared to the determine which performs better so it’s used to optimize user experience and marketing strategies.
    - A website can run a AB test by showing one group of users the original design which is A and another group of user a new design which is B and then analyze which version leads to a higher click through rate.
24. Hypothesis Testing
    - This is statistical method used to determine if there is enough evidence to support or reject a claim about a population based on a sample.
    - A food delivery app might use hypothesis testing to determine if a new discount strategy significantly boost order numbers or maybe if that’s not the case.
25. Predictive Modeling
    - It involves using historical data to create a model that predicts future outcomes.
    - For instance, a insurance company uses predictive modeling to assess risk factors and estimate future claims.
26. SQL
    - Structured Query Language (SQL) which is a language used for managing and querying relational databases.
    - It’s crucial for data retrieval and manipulation.
    - For instance, a hotel chain can use SQL to track room occupancy and me as a data antic lead I use it pretty much on a daily basis.
27. Python Libraries
    - Python libraries are a collections of modules or functions that provide a specific functionality of features.
    - They help avoid the reinventing the wheel by providing pre-written code for common tasks. These obviously make it easier and more efficient to perform specific tasks.
    - In data analytics, the most common are NumPy for numerical operations, Pandas for data manipulation and analysis, Matplotlib for data visualization and plotting, scikit-learn for machine learning tasks and tensor flow for deep learning.
28. MoM & YoY
    - Month over Month and Year over Year are comparisons of data between consecutive months or the same month in different years respectively.
    - For example, if a company had sales of $100 in January and $110 in February the month of a month sales growth would be 10% and if a company had sales of 100 in February 2022 and 120 in February 2023. The year-over-year sales growth for February would be 20%.
29. YTD
    - Year to date which refers to the period of time from the beginning of the current calendar year up to the present date.
    - YTD is used for tracking financial performance and trends.
    - For example, imagine that today it’s August 1st 2023, the year to date refers to the time from January 1st to August 1st 2023.
30. KPI
    - Key Performance Indicator which is a measurable volume that reflects how effectively a business is achieving its objectives.
    - For example, a e-commerce company might track kpi like conversion rate and average order value to understand the website performance.
31. Clustering
    - Clustering is a machine learning technique that group similar data points together based on their characteristics and it’s used for segmentation and pattern recognition.
    - For example, a marketing team can apply clustering to a group customers with similar purchase behaviours allowing basically tailoring marketing strategies to boost their customer engagement.
32. Classification
    - It is another machine learning task where the goal is to predict the category or class of an object based on its features and it’s used for various applications like fraud detection.
    - For example, a bank can employ classification to automatically identify fraud and transactions by analyzing transaction patterns and obviously safeguarding customers financial security.
33. Feature Engineering
    - Feature engineering is the process of selecting, transforming, and creating new features from raw data to improve machine learning model performance.
    - In email spam classification, features like email length, number of exclamation marks and presence of certain keywords can be engineer to help the model distinguish between a spam and a legitimate emails.
34. Ensemble Learning
    - Ensemble learning which is a technique that combines multiple machine learning models to improve predictive performance and reduce overfitting. In medicine combining predictions from multiple algorithms like random forest gradient boosting and neural networks can provide a more reliable diagnosis by reducing individual model, biases and errors.
35. NLP
    - Natural Language Processing is a field of AI focused on enabling computers to understand, interpret and generate human language.
    - In the industry, NLP is used for task like sentiment analysis or chatbots and also language translation.
    - For example, NLP helps customer service chatbot understand user queries and respond intelligently.
