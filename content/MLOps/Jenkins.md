# Brief Introduction
- Jenkins is an open source automation server that helps developers automate the process of building, testing and deploying software.
- Jenkins can automate the entire software development lifecycle and achieve continuous integration and delivery.
- Jenkins simplify the development process by automating repetitive tasks such as building, testing and deployment.
