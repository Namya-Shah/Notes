```neovim
i -> Insert mode
esc -> Normal Mode
: -> Command Mode
l -> Cursor goes Right
h -> Cursor goes Left
j -> Cursor goes Down
k -> Cursor goes Up
$ -> End of the current line
0 -> Starting of the current line
w -> Moves forward a word at a time
e -> Moves forward but cursor stucks at end character of the word
b -> Moving back of every word
gg -> First line of the file
G -> Last line of the file
u -> Undo any changes made to file
Ctrl(^) + r -> Redo any changes made to file
A -> Append mode which goes into insert mode at the end of the current line
o -> Open a new line below the current line
O -> Open a new line above the current line
dd -> Deletes whole current line
cc -> Deletes whole current line and enter insert mode
di{ -> Deletes everything inside the {} braces
ci{ -> Deletes everything inside the {} braces and insert mode
} -> Next empty line
{ -> Previous empty line
v -> Visual Mode
y -> Copy text that is highlighted
p -> Paste text
/ -> Used to search for the next occurence
:%s/{name}/{replaced_name} -> Search and replace text

```
