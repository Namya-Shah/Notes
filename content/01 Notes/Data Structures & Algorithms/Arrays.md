# [[Bubble Sort]]
- Bubble sort is one of the simplest sorting algorithms. It works by **repeatedly swapping adjacent elements** if they are in the wrong order.
- Simple sorting for small datasets or nearly sorted data, like sorting a deck of cards.
# [[Selection Sort]]
- Selection sort is another simple algorithm that works by **repeatedly selecting the smallest element** from the unsorted portion of the array and moving it to the front.
# [[Insertion Sort]]
- Insertion sort is a simple and efficient algorithm that works by **building a sorting list one item at a time**. It's good for small datasets but can be slow for larger ones.
# [[Quick Sort]]
- Quick sort is a popular algorithm that works by **partitioning an array into two smaller ones**, then recursively sorting each partition.
- Fast sorting of large datasets, widely used in database systems.

# [[Radix Sort]]
- Radix sort is a type of sorting algorithm that only **works with numbers (integers) in a restricted range**. We iterate through each digit of the number, and group numbers by each digit. Then, we sort each of these groupings by the next digit.
# [[Merge Sort]]
- Merge sort is another popular algorithm that works by **dividing the array into smaller subarrays**, sorting each one, then merging them back together.
- Efficient sorting for large datasets, often used in external sorting.
# [[Linear Search]]
- Finding an element in an unordered list, like searching for a name in a phone book.
# [[Binary Search]]
- Searching in an ordered list, such as finding a word in a dictionary.
# [[Shell Sort]]
- Shell sort is an extension of insertion sort that **compares elements that are far apart and gradually reduces the gap** until it becomes 1. At this point, the algorithm becomes equivalent to insertion sort.
# [[Heap Sort]]
- Heap sort is a comparison-based sorting algorithm that works by first **organizing the data into a heap**, then extracting the largest element and placing it at the end of the array.
